COURSE CONTENTS

Click any module to view detailed syllabus topics

01 Introducing Power BI

Power BI introduction, installing Power BI, comparison Power BI vs Tableau, uses of Power BI, basic components of Power BI.

02 More About Power BI

Features of Power BI, benefits and advantages, Power BI Desktop, Service, Mobile apps, explain the role of reports, data and model views.

03 Connecting To Data Sources

Identify and connect to data sources, data collected from different sources.

04 Integration With Other Tools And Data Sources

Using Analyze in Excel features, exporting Power BI data to Excel, connecting with advanced data sources.

05 Modelling The Data – Creating Relationship

Build the relationships, creating more relationships.

06 Transforming Data in Power BI

Basic transform, combine data and add column from example, dashboard creation from pre-existing report.

07 Data Modelling And Relationship

Importance of data models, build relationships (one to many, many to one), primary and foreign keys.

08 Visualization Of Data in Power BI

Introduction to visualization data, create interactive reports using slicer for filter, tabular data, categorical data, data trends and other features, visualizing goal tracking.

09 Advance Visualization

Creating report (digital storytelling), using Power BI Q&A and Excel integration, manually typing data table.

10 Filters And Slicers

Different types of filters (visual, page and report level), adding different slicers and filters to report.

11 Advanced Tooltips and Bookmark

Using bookmarks for navigation and storytelling, creating customized tooltips.

12 Creating And Customizing Visuals

Customizing theme, customizing visuals (labels, colors, title), formatting reports and visuals for readability, interactions between visuals.

13 Power Map in Power BI

Mapping geographical data, exploring visualization options, working with multiple scenes.

14 Power BI Hierarchies and Filters

Creating hierarchies in Power BI, drill-down options, drillThru options and report, type of filters, TOP N filters.

15 Introduction To Power Query

Power Query introduction, query editor, row transformation, data type and adding column, replace column, move and replace column.

16 Advanced Power Query

Advanced features in Power Query, text & number transformations, date, time & structured data, merge and append transformation.

17 Pivot Table in Power BI

Building Pivot Table on top of Power Pivot, using Pivot Chart.

18 Introduction To Power DAX

Introduction to DAX, importance of DAX, step to create calculated column.

19 Authoring Power View Report

Create tables & metrics, from table to chart, interactive sorting, filtering & highlighting, working with bubble chart, slicers, card and multiples, adding map with multi-view reports.

20 Publishing And Sharing Reports

Step to publish reports, difference between dashboards and reports, pinning visuals to dashboards, sharing reports and dashboards with others.

01 Introduction and Formatting of Excel Workbook

Introduction to Excel interface, understanding rows and columns, naming cells, working with Excel workbook and sheets, New, Open, Close, Save, Save As, formatting text (Font Size, Font Style, Font Color, Bold, Italic, Underline), Wrap text, Merge and Centre, Currency, Accounting and other formats, modifying columns, rows & cells.

02 Introduction to Excel Calculations

Creating simple formulas, setting up your own formula, Date and Time Functions, Financial Functions.

03 Perform Calculations with Excel Functions

Logical Functions, Lookup and Reference Functions, Mathematical Functions, Statistical Functions, Text Functions.

04 Sort and Filter Data in Excel

Sort and filtering data, using number filter, text filter, custom filtering, removing filters from columns, conditional formatting.

05 Create Effective Excel Charts to Present Data Visually

Inserting Column, Pie chart etc., create an effective chart with Chart Tool Design, Format, and Layout options, adding chart title, changing layouts, chart styles, editing chart data range, editing data series, changing chart.

06 Analyse Data Using Excel PivotTables and Pivot Charts

Understand PivotTables, create a PivotTable framework using the PivotTable and PivotChart, create Pivot Chart from Pivot Table, inserting slicer, creating calculated fields.

07 Use Excel Scenarios

Use What-If Analysis Tools, create scenarios, merge scenarios, create scenario summaries, use data tables, create advanced charts, basic Excel charts, use Area, Scatter & Stock charts, use Surface, Radar & Combination charts, create custom chart templates, work with Sparklines.

08 Protecting and Sharing the Excel Workbook

Protecting a workbook with a password, allow user to edit ranges, track changes, working with comments, insert Excel objects and charts in Word document and PowerPoint presentation.

09 Advance Formulae and Functions in Excel

Create advanced formulae, functions, apply functions in formulae, Mathematical functions, Financial functions, Useful Data functions, some other useful functions, look up data by using functions, apply advanced date and time functions, functions for manipulating text, arrays.

10 Apply Custom Formats and Layouts to Excel Worksheets

Apply custom data formats, use advanced fill options, apply advanced conditional formatting and filtering, apply custom styles and templates, use form controls, prepare workbooks for internationalization, use outlines, use custom views.

11 Advance Features in Microsoft Excel

Creating and recording macros, assigning macros to the worksheets, saving macro-enabled workbook, page setup, setting print area, print titles, inserting custom header and footer, inserting objects in header and footer, setting margins, print preview, print, enable background error checking, setting AutoCorrect options.

12 Advanced Excel Function Implementation Project

Two-Way Lookup, using dropdown lists as lookup values, three-way lookup, getting the last value from a list, partial lookup using wildcard characters and VLOOKUP, VLOOKUP returning an error despite a match in lookup value, doing a case sensitive lookup, using VLOOKUP with multiple criteria, handling errors while using the VLOOKUP function.

13 Manage and Share Excel Workbooks

Manage workbook versions, copy styles within workbooks, copy macros within workbooks, use track changes and comments, merge workbooks, protect workbooks for sharing, connect to external data.
